# Contributing

This repository is generated: each public release is copied from the project's private working repository by a
release pipeline, as one commit. Issues and pull requests are welcome. A pull request is not merged here directly;
the change is ported by hand into the working repository and arrives with the next release, so the next release
would otherwise overwrite it.

Numbers such as `R-69`, `AD-P13-21` or `OQ-12` in code comments refer to the project's private design record.
